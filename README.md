# Bestie Birthday Surprise Website 💗

## Open in VS Code
1. Extract this ZIP.
2. Open the `bestie-birthday-surprise` folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.

## Personalize
Open `script.js` and edit the `birthdayData` object near the top:
- `friendName`
- `birthdayMessage`
- `letter`
- `memories`

Replace:
- `images/photo1.jpg`
- `images/photo2.jpg`
- `images/photo3.jpg`
- `images/photo4.jpg`

with your own photos, keeping the same filenames.

## Optional music
Put your audio file at:
`music/birthday.mp3`

The starter site does not autoplay audio because browsers commonly block autoplay. You can add a music toggle later if wanted.

## Deploy to Netlify
### Easiest method
1. Go to Netlify.
2. Choose **Add new project / Deploy manually**.
3. Drag the extracted `bestie-birthday-surprise` folder into the deploy area.
4. Netlify will publish the static website.

No build command or framework is required.

## Notes
- The quiz has 10 questions and a working score.
- The memory answer is saved in browser localStorage.
- Photo placeholders automatically appear if the sample image files are missing.
- The site is responsive for mobile screens.
- Arrow keys can move between pages.
